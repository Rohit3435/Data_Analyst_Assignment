# Data Analyst Assignment

## Project Overview

This project performs end-to-end exploratory and business data analysis across multiple related datasets.

The objective was to understand the datasets, identify data-quality issues, perform validation checks, generate business insights, calculate key performance indicators, and provide recommendations.
